# Кредитный скоринг Альфа-Банка — версия 3

**ROC-AUC на отложенной выборке: 0.7405** (было 0.59–0.61 в версиях 1 и 2).

## Что было не так в версиях 1–2

В данных у каждого клиента (`id`) несколько строк — по одной на каждый его кредит
(`rn` — номер кредита, в среднем ~8 кредитов на клиента). Целевая переменная
(дефолт) одна на клиента.

Версии 1–2 учили модель на **отдельных строках-кредитах**:

- метка клиента копировалась на все его кредиты, и модель путалась;
- в версии 1 статистики группировались по `rn` («все первые кредиты всех клиентов вместе»),
  а не по `id` («все кредиты одного клиента»);
- признаки строились для каждой из ~24 млн строк → кончалась память
  (именно поэтому падали ноутбук и Kaggle — дело было не в железе).

## Что сделано в версии 3

1. **`features.py`** — история каждого клиента сворачивается в одну строку:
   - все признаки — категориальные коды, поэтому для каждого значения каждого признака
     считается, сколько кредитов клиента его имеют (one-hot + сумма по клиенту);
   - то же самое отдельно по **трём последним** кредитам клиента;
   - число кредитов.

   Итого 3 млн строк × 811 признаков (uint8). Обработка порциями ~50 тыс. клиентов,
   чтобы не упираться в память.
2. **`train.py`** — LightGBM:
   - убраны почти пустые признаки (≤0.2% ненулевых) → 587 признаков;
   - обучение на 7 файлах (1.75 млн клиентов), валидация на файле 11 (250 тыс.);
   - early stopping по AUC, лучшая итерация 411, ~14 минут на 2 ядрах.

## Что нашла модель

Из 15 самых важных признаков 9 — про **последние три кредита** (`last3_*`).
Свежее поведение клиента говорит о риске больше, чем вся история.

## Файлы

| Файл | Что это |
|---|---|
| `features.py` | сборка признаков по клиентам |
| `train.py` | обучение, валидация, предсказания |
| `train.log` | лог обучения (AUC по итерациям, важность признаков) |
| `model_v3.txt` | обученная модель LightGBM |
| `submission_v3.csv` | предсказания для 500 тыс. клиентов теста |

## Запуск

Данные (`train_data/`, `test_data/`, `train_target.csv`) лежат в репозитории `Version_2_alfa`.

```
pip install pandas pyarrow lightgbm scikit-learn
python features.py <папка_с_данными> feats
python train.py <папка_с_данными> feats
```

## Что можно улучшить

- обучить на всех 12 файлах (нужно ~12+ ГБ памяти);
- добавить признаки по 1-му и последнему кредиту, доли вместо счётчиков;
- CatBoost/усреднение нескольких моделей — обычно ещё +0.005–0.01 AUC.
